One image summing up Thursday 19 November 2026: the first-ever
Trump–Xi–Putin summit in Shenzhen signs a peace declaration, GTA VI
launches worldwide, NASA confirms Voyager 1 is one light-day out, a
lockdown empties Dhaka, Cyclone Akvan evacuates 47,000 in Odisha, and
Iranian drones strike Kuwait and Bahrain.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` (1024×1024, drawn with PIL) to the output
directory. The program uses only the Node standard library and writes
identical bytes on every run.
